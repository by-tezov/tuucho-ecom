# Studio note (example page plugin)

Drop-in extra storefront page. The folder name must match `id` in `plugin.json`.

1. Copy this folder to `back/plugins/your-id/`.
2. Edit `plugin.json` (`id`, `name`, `route`, `nav.key`).
3. In admin: **Plugins**, then **Scan for new plugins**.

Settings (`title`, `body`) are editable on that plugin card.
See `/docs/plugins.md`.
